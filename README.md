# Outreach Hub

Create a modern and mobile-friendly Work Management Dashboard named “Works by B School Buzz”. The platform should have a clean and professional UI with both Light Mode and Dark Mode support. The dashboard should be simple, fast, visually attractive, and fully responsive for desktop, tablet, and mobile devices.

The main module of the dashboard will be “Outreach”. Inside Outreach, there should be two dropdown sections named “Colleges” and “Coaching”. Both sections should have the exact same workflow and structure.

In the Colleges section, the admin should be able to create a new college profile. While creating the profile, the admin can add the college name, city, state, official website link, contact details, multiple email addresses, and multiple mobile numbers. There should be dynamic add buttons so the admin can continuously add more emails and phone numbers whenever required. Once submitted, the college profile should be saved and visible in the dashboard list.

After creating the profile, the admin should be able to manage the outreach process through customizable stages. Example stages can include First Email Sent, Second Email Sent, Follow Up Done, Meeting Scheduled, Meeting Completed, Collaboration Discussion, Proposal Sent, and Deal Closed. These stages should be manageable from the Admin Settings panel where new stages can be added, edited, deleted, or reordered anytime. The same outreach stages should automatically apply to both Colleges and Coaching sections.

Each profile should show the complete outreach timeline and current status. The admin should be able to update stages easily with one click. Add filters, search options, progress indicators, and status tracking to make outreach management smooth and organized.

The dashboard homepage should display total colleges added, total coaching institutes added, ongoing outreach count, completed outreach count, upcoming meetings, and recent activity logs. The design should feel modern, premium, minimal, and highly user-friendly with smooth navigation and proper spacing.

Keep the overall structure simple, scalable, and easy to manage from the admin side. The platform should focus on clean workflow management, outreach tracking, and efficient communication handling.
